# Food Machine

By default the food machine will allow any food items to be turned into food cubes;
Dalek Mod 1.20 gives you more control over which items can be used in the food machine.

## Allowing Items
To allow items, you can add them to the `dalekmod:foodcubeable` item tag.

## Disallowing Items
To disallow items, you can add them to the `dalekmod:unfoodcubeable` item tag.
