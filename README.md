# Dalek Mod Developer Wiki

This is a developer wiki made for anyone interested in developing for Dalek Mod, whether it be addon mods, data packs or anyone else. This wiki is made with [GitHub Pages](https://docs.github.com/en/pages) and [Just the Docs](https://just-the-docs.github.io/just-the-docs/).

If you wish to add to the wiki, don't be afraid to open a pull request.
