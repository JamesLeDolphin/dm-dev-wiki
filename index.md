# 1.20 Addon Dev Wiki

This wiki will contain information useful for making addons for Dalek Mod 1.20. It will go over the basics of adding new content via datapacks, resource packs and addon mods. 

Dalek Mod 1.20.1 no longer uses JavaJSON, and has instead switched to GeckoLib 4. 
Old JavaJSON models are not supported and will need to be converted to geckolib in order to work. 
[How to make GeckoLib models.](https://github.com/bernie-g/geckolib/wiki/Making-Your-Models-(Blockbench))

If you have any questions, don't be afraid to ask in the [SWD Discord](https://swdteam.com/discord).
